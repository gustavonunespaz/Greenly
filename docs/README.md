# Documentação (`docs/`)

Este diretório concentra documentos de referência macro para as decisões de ciclo de vida e tecnologia do Greenly.

## Documentos ativos

- `plano_acao_benchmarking_ambisis.md`
  - Plano mestre de evolução detalhado por ondas e sprints, servindo de diretriz principal para todo o desenvolvimento.
- `analise_de_benchmarking_de_solucoes_digitais.docx`
  - Documento base detalhado usado para decisões de alto nível deste projeto.
- `OBRIGACOES_AMBIENTAIS_OFICIAIS.md`
  - Padrão oficial implementado para obrigações ambientais (IBAMA, SINIR e IAT), incluindo regras de prazo, endpoints, banco e front.
- `FLUXO_DOCUMENTAL_CRUD_FRONTEND.md`
  - Guia operacional do fluxo de upload documental no frontend até o aceite e aplicação no CRUD.

## Regra de manutenção

Antes de criar novo documento para features ou novos módulos, valide se o conteúdo pode e deve entrar diretamente no arquivo `plano_acao...` que atua como nosso backlog vivo ou em um `README.md` específico dos `apps/` afetados.
